# MDRT Certificate Generator - Quick Start

## 🚀 Start the Application

### **Easiest Method:**
**Double-click `start.bat`**

That's it! Wait 15 seconds, then browser opens automatically.

---

## 📱 What You'll See

### **Two Terminal Windows:**
1. **MDRT Backend** (Flask API) - Port 5000
2. **MDRT Frontend** (React UI) - Port 3001

### **Browser Opens To:**
http://localhost:3001

---

## ✅ You Should See:

- Purple gradient header
- "MDRT Certificate Generator" title
- 4-step wizard interface
- Upload file sections

---

## 🛑 To Stop

Close both terminal windows or press **Ctrl+C** in each.

---

## 🔄 To Restart

1. Close both terminals
2. Double-click `start.bat` again

---

## ⚡ URLs to Remember

- **App**: http://localhost:3001
- **Backend Health Check**: http://localhost:5000/api/health

---

## ⚠️ Important

- **Keep both terminals open** while using the app
- **First startup** takes 30-60 seconds (React compiling)
- **Don't close terminals** until you're done
- Port changed to **3001** (3000 had conflicts)

---

## 🎯 Next Steps After Starting

1. **Upload Assets** (Step 1):
   - 3 background images (MDRT, COT, TOT)
   - 3 badge images (LM, HR, QC)
   - 1 font file (.ttf)
   - 1 CSV data file
   - All agent photos

2. **Configure Positions** (Step 2):
   - Adjust coordinates for photos, text, badges

3. **Process Certificates** (Step 3):
   - Click "Start Processing"
   - Wait for AI background removal

4. **Download** (Step 4):
   - Download all as ZIP
   - Or download individually

---

**That's it! Simple as double-clicking `start.bat`** 🎉
